# URLs de ejecución y entrega

| Entorno | Dirección | Estado |
| --- | --- | --- |
| Interfaz local | [Vite](http://localhost:5173/) | Puerto inicial; usar la URL que informe Vite. |
| API Apache | [Categorías](http://localhost/tienda_online/api/categorias/index.php) | Ruta de comprobación local. Apache puede utilizar 8080. |
| Producción | [TodoAquí](https://proyecto6-dfs-intecap2026.x10.mx/) | Dominio informado; SSL validado según el propietario. No comprobado externamente en esta tarea. |
| GitHub | Sin URL registrada | Se eliminó el vínculo al repositorio por conflictos; el entregable actual es local. |

El hosting y la copia local tienen diferencias intencionales. No usar la carpeta local como reemplazo automático del sitio publicado. HTTPS no confirma que funcione SMTP del hosting. Véase [Estado](TRANSFERENCIA_ESTADO.md).
