# Tecnologías utilizadas

## Frontend
- HTML5 mediante JSX
- React para componentes y estado de interfaz
- Vite para servidor de desarrollo y build
- Bootstrap 5 para grilla, formularios, utilidades y componentes visuales
- SCSS para estilos propios y comportamiento responsivo
- JavaScript para interacciones, carrito, filtros, autenticación y consumo de API

## Backend
- PHP para endpoints y reglas de negocio
- PDO para acceso seguro a MariaDB
- Sesiones PHP para autenticación
- Arquitectura separada en modelos, controladores y endpoints API

## Base de datos
- MariaDB como base relacional transaccional
- SQL con claves primarias, foráneas, restricciones y transacciones
- Diseño NoSQL complementario documentado para MongoDB

## Seguridad y buenas prácticas
- Contraseñas con `password_hash` y `password_verify`
- Consultas preparadas
- Control de roles
- Validación de entrada
- Manejo consistente de respuestas JSON
- Separación de responsabilidades
- Convención de nombres documentada
