# TodoAquí — entregable local

Proyecto académico de tienda en línea con React, PHP, MariaDB, MongoDB Atlas y correo de prueba Ethereal.

- [Instalación y ejecución](docs/INSTALACION_LOCAL.md).
- [Índice de documentación](docs/README.md).
- [Arquitectura y directorios](docs/ARQUITECTURA.md).
- [Estado vigente](docs/TRANSFERENCIA_ESTADO.md).
- [Pruebas](docs/CASOS_PRUEBA.md).

La copia en `C:\xampp\htdocs\tienda_online` es la versión vigente del entregable y no tiene repositorio Git activo. El usuario confirmó conexión con Atlas y creación de una orden con correo capturado en Ethereal. `build` contiene la copia subida al hosting e `INFORME` el material separado de informe; ambos quedan fuera de esta documentación técnica.

En una instalación ya configurada, iniciar Apache y MariaDB y ejecutar `npm.cmd run dev` desde la raíz. Abrir la dirección que indique Vite. Consultar la guía antes de preparar otra máquina.

El proyecto registra operaciones académicas; no procesa cobros bancarios ni emite facturas fiscales.
